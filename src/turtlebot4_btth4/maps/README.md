Thư mục này nhận `map.yaml` và `map.pgm` khi bạn chạy `bash ~/turtlebot4_btth4_ws/save_map.sh` sau khi tự khảo sát bằng TurtleBot 4 Standard.

Chỉ chạy localization/Nav2 sau khi có hai file này. Không dùng bản đồ minh chứng của phiên chạy khác. Khi hoàn thành, đưa cả hai file lên nhánh `assignments_4` để thầy có thể load bản đồ của bạn.
